# プロジェクトの概要とエージェント設定

## 何のための機能か

プロジェクトを開いたとき、最初に「いまこのプロジェクトはどういう状態か」をひと目で見せます。
あわせて、エージェントがこのプロジェクトで読む「スキル」と「指示ファイル」をまとめて一覧し、
どんな前提でエージェントが動くのかを確かめられるようにします。

## 誰がいつ使うか

- プロジェクトの一覧からプロジェクトを開いた人が、変更の量や動いているセッションを確かめるとき。
- 新しいセッションを、そのプロジェクトで始めたいとき。
- エージェントに渡る指示（AGENTS.md など）やスキルが、期待どおり見つかっているかを確かめたいとき。

## 画面のどこにあるか

「プロジェクト」ページでプロジェクトを開くと、見出しの下にタブが並びます。

- 「概要」は一番左のタブで、プロジェクトを開いたときに最初に表示されます。
- 「エージェント設定」は左から 6 番目のタブ（「ファイル」の右、「ナレッジ」の左）です。

## 今できること

- 「概要」に 3 つの数字のタイル「セッション」「未コミットの変更」「worktree」が並ぶ。
  読み込み中や取得に失敗したときは数字の代わりに「—」が出ます。
- 「新しいセッション」ボタンで、そのプロジェクトを選んだ状態の起動画面を開く。
- 「このプロジェクトのセッション」に、新しい順に最大 8 件のセッションが並ぶ。行は「ホーム」と同じ見た目で、
  押すとそのセッションを開けます。
- 「エージェント設定」の上段「スキル」に、プロジェクト内で見つかった `SKILL.md` のパスが並ぶ。
- 下段「ルールと指示」に、`AGENTS.md`・`CLAUDE.md`・`GEMINI.md`・`CODEX.md`・`INSTRUCTIONS.md` のパスが並ぶ。
- それぞれの見出しの横の更新ボタンで、探し直す。
- それぞれの行の目のアイコン（「「ファイル」タブで開く」）で、そのファイルを「ファイル」タブのエディタで開く。

## 今できないこと・既知の制約

- 「概要」は読むだけの画面です。変更の中身やセッションの操作はそれぞれのタブとページで行います。
- 「セッション」のタイルは、完了したものを含めそのプロジェクトのセッションの総数です。一覧は最新の 8 件までです。
- 探すのはプロジェクトのフォルダの中だけです。スキルは最大 80 件、指示ファイルは最大 200 件まで。
  それを超えたり、読み取れないフォルダがあったりすると、警告の 1 行が出ます。
- 見つからないときは「SKILL.md は見つかりませんでした。」「プロジェクトの指示ファイルは見つかりませんでした。」と出ます。
- 「スキル」の説明文は「プロジェクトと各エージェントのフォルダで見つかった SKILL.md です。」と書いてありますが、
  実際に探しているのはプロジェクトのフォルダの中だけです（各エージェント自身のフォルダは探しません）。
- ここからスキルや指示ファイルを新しく作ることはできません。開いて編集するだけです。
