# 新しいセッション

## 何のための機能か

エージェント(Codex・Claude Code・Antigravity、または自分で決めたコマンド)を、どのプロジェクトのどの場所で、何を頼んで、どんな設定で動かすかを決めて、セッションを起動する機能です。

エージェントの権限や設定は CLI 自身の選択肢から選びます。Operon が独自のフラグを作ることはなく、確認なしでファイルを変えられる危険な設定には、必ず確認を求めます。

## 誰がいつ使うか

- 新しい作業をエージェントに任せるとき。
- 同じ依頼を複数のエージェントに同時に渡して、結果を見比べたいとき。
- 前に使った設定を毎回選び直したくないとき。
- 既存の会話の続きを、会話 ID を指定して再開したいとき。

## 画面のどこにあるか

どのページからでも、「新しいセッション」(⌘N)でいまのページの上にシートが開きます。ページは切り替わりません。

- 上から「エージェント」「アカウント」(Claude Code と Codex で、登録済みのときだけ)「依頼（任意）」「作業場所」「詳しい設定（任意）」の順に並びます。
- シート上部のプロジェクト一覧で起動先のプロジェクトを選べます。最後は「新しいプロジェクト…」で、「プロジェクトフォルダを開く」シートが開き、パスを入力するかフォルダの一覧から選んで追加できます（まだ無いフォルダは確認のうえ作れます）。ウィンドウへ落としても追加できます。
- 右下に 「〈エージェント名〉 を起動  ⌘↩」、左下に 「ターミナルだけ開く」があります。
- タブ列の「+」を押すと、「ターミナル」と各エージェントの小さなメニューが開きます。シートを開かずに、そのペインですぐ起動できます。

## 今できること

- エージェントを選ぶ。この Mac で使えるものには印が付く。「別のコマンドを使う」では「起動コマンド（必須）」を入力する。
- 依頼を書く。「テンプレートを挿入」で組み込みの依頼(diff のレビュー、CI エラーの修正、マージ競合の解消、テストの追加)か、リポジトリの `.operon/prompts/` にある自作の依頼を入れる。
- 「GitHub Issue から取得…」で、オープン中の Issue を選ぶと依頼とセッション名が入る(`gh` が必要)。
- `@` を打つと `@diff`、`@knowledge:<題名>`、プロジェクトのファイルが候補に出る。これは文字として入るだけで、エージェントが読みに行く。
- 作業場所を「プロジェクト直下」か、作ってある worktree から選ぶ。「作業フォルダを Finder で表示」もできる。
- 「詳しい設定（任意）」で、セッション名、モデル、モードや権限の選択、「推論の深さ」、その CLI のスイッチ、「追加の引数（任意）」、「再開する会話 ID（任意）」、「ほかのセッションの後に開始」を指定する。
- 「複数エージェントで並走（別 worktree で比較）」で、2 から 3 のエージェントに同じ依頼を渡す。それぞれ専用の新しい worktree と branch で動く。Git のプロジェクトのときだけ出る。
- 最後に使ったモデル・モード・推論の深さ・スイッチ・コマンド・追加の引数を、エージェントごとに覚えて次回の初期値にする。
- 「この設定を毎回使う」で、エージェント・設定・アカウントの組み合わせを固定し、シートを開くたびにそれで始める。
- 起動中は、「作業フォルダ」「プロジェクト」「エージェント」「起動コマンド」を示す進行表示が出る。失敗すると理由が出て、「再試行」「設定を開く」「閉じる」を選べる。

## 今できないこと・既知の制約

- 起動ボタンは、起動コマンドが空、tmux がない、選んだエージェントが見つからない、worktree の操作中、危険設定の確認が未チェックのどれかで無効になり、理由が表示されます。
- 危険な設定(確認なしでファイルを変更できるスイッチやモード、任意コマンドの該当フラグ、追加の引数)は、「理解したうえで起動する」にチェックを入れるまで起動できません。引数を編集すると、そのチェックは外れます。
- 追加の引数は `--` で始まるスイッチだけです。値は `--name=value` と書きます。シートがすでに持つ項目(`--model` など)は重ねて指定できず、最大 1,024 文字です。
- 会話 ID を指定した再開では、依頼を同時に書けません。不正な ID、Antigravity の「新しいプロジェクトとして開始する」との併用も断られます。ID は記憶されず、起動後に消えます。
- CLI が同時指定を拒否するスイッチは、同時にオンにできません。
- 並走は Git のプロジェクトで、使えるエージェントが 2 つ以上あるときだけ使えます。ブランチ名は「基本名-エージェント名」になります。
- 前提のセッションが失敗したり中止されたりしても、待機中のセッションは自動では開始されません。ブロック状態になります。
- 「ターミナルだけ開く」は tmux が必要です。
- タブ列の「+」で起動するエージェントは、依頼なし、覚えてある設定で始まります。危険な設定が必要な場合は起動せず、シートを開いて確認を求めます。
- 使えないエージェントは「+」のメニューで選べず、「未準備（設定で確認）」と表示されます。
