# ナレッジ

## 何のための機能か

プロジェクトでエージェントと交わした会話から、決定・原因・手順・注意・事実を短いメモ(ナレッジ)にして残す機能です。あとのセッションのエージェントが、前に分かったことを調べ直さずに済みます。

誰にも使われないメモは薄れて消え、参照されたり何度も出てきたりするメモは残ります。

## 誰がいつ使うか

- 同じプロジェクトで何度もエージェントを動かしていて、前回の発見が毎回失われていると感じるとき。
- 「この判断はなぜそうしたのか」を、会話を遡らずに確かめたいとき。
- 蓄積したメモの全体像を見たいとき。

## 画面のどこにあるか

プロジェクトの詳細にある「ナレッジ」タブです。モデルの取得と削除は「設定」の「データと復旧」にもあります(「意味検索（EmbeddingGemma 2）」)。

- 有効にする前は、機能の説明と 「このプロジェクトでナレッジを集める」 ボタンが出ます。
- 有効にしたあとは、見出し「ナレッジ」の下に状態の行(「N 件 ・ 最終更新 … ・ EmbeddingGemma 2 (…) ・ 本日の判定 N/30 回」)があります。
- 「表示:」で「一覧」と「マップ」を切り替えます。「並び:」(「鮮度」「参照回数」「新しい順」)と「種類:」(「決定」「原因」「手順」「注意」「事実」)で絞り込めます。検索欄は「ナレッジを検索」です。

## 今できること

- プロジェクトごとにナレッジの収集を有効にする。初回は 「モデルを取得して始める (310MB)」 で、意味を判定するモデルを 1 回だけ取得して検証する。モデルはこの Mac の中で動き、会話の内容は外に出ない。
- 約 10 分ごと(起動の約 30 秒後が最初)に、新しい会話を自動で処理する。「今すぐ更新」で手動でも実行できる。
- 残す価値のある少数のやり取りだけを、その会話を行った CLI(Claude Code・Codex・Antigravity)に頼んで要約する。使えなければ、使える別の CLI に切り替わる。
- 各メモに「検証済み」か「未確認」が付く。検証済みは、テストやコマンドの出力、または本人の確認で裏づけられたもの。
- 後の会話で誤りと分かったメモは、新しい内容に置き換わる(固定したメモは置き換えない)。
- メモを「固定」すると薄れなくなる。不要なメモは「削除」できる。「会話を開く」で元の会話に移る。
- 「マップ」で、意味の近いメモを近くに並べた 2D の図を見る。グループごとに囲み、点の形が種類を、大きさが参照の多さを、濃さが鮮度を表す。ドラッグで動かし、スクロールで拡大する。
- Claude Code と Codex のセッション開始時に、最大 10 件のメモの題名と検索方法がその CLI に渡される。固定・検証済み・最近使われたものが先になる。
- エージェントは `Operon knowledge search "検索語" [--limit N] [--json]` で検索できる。
- 「収集を止める (ナレッジは残す)」で止め、「ナレッジを削除…」で消す。

## 今できないこと・既知の制約

- プロジェクトごとに自分で有効にしないと何も集まりません。モデルがないと収集は止まります。
- 要約を頼む回数は、プロジェクトごとに 1 日 30 回までです。上限に達すると翌日に続きを処理します。
- メモは 1 プロジェクト 2,000 件までです。固定したメモが 2,000 件に達すると、新しいメモは追加されません。
- 1 回の更新で処理する会話は 20 件、時間は 180 秒までです。
- メモの題名は 40 字、本文は 400 字までです。
- 3 回続けて処理できなかった会話は、7 日あいだを置いてから再試行します。「再試行」で手動でもやり直せます。
- ナレッジはこの Mac だけに保存され、リポジトリには置かれません。ほかの Mac とは共有できません。
- セッション開始時にメモの題名を渡すのは Claude Code と Codex だけです。Antigravity のセッションには渡されません(Antigravity との会話から作られたメモの題名は、Claude Code と Codex には渡されます)。
- マップの配置は最大規模(2,000 件)で約 5 秒以内を目安にしています。
