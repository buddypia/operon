# ターミナルペイン

## 何のための機能か

セッションの中身であるターミナルを、Operon の中で直接見て、そのまま操作するための画面です。エージェントの出力を読み、質問に答え、出てきたファイルのパスや開発サーバーの URL をたどれます。複数のセッションを同時に並べて見張ることもできます。

## 誰がいつ使うか

- エージェントの作業を見守り、必要なときに入力して指示を足したい人が、いちばん長く開いている画面です。
- 2 つ 3 つのセッションを並べて、進み具合を見比べたいときに分割して使います。
- 出力中に出てきた 「src/foo.rs:42」のようなパスを、そのままエディタで開きたいときに使います。

## 画面のどこにあるか

- セッションページ(⌘3)の中央です。左にセッション一覧、右にサイドパネル(ファイル・会話・変更)があります。
- 上にタブの列があり、最後のタブの右に「＋」(「ターミナルや AI を起動」)があります。
- 各ペインの上部に、「プロジェクト / 題名」の見出し、状態、開始・停止・再開のボタン、「⋯」(その他の操作)があります。サーバーが開いているポートも、ここに出ます(例: 「:5173 vite」)。
- ペインの右下に「最新へ」ボタンがあります。
- ウィンドウの縁へタブをドラッグすると、その側に分割されます。

## 今できること

- タブでセッションを切り替える。⇧⌘] と ⇧⌘[、または ⌃Tab と ⌃⇧Tab で次・前へ、⇧⌘T で閉じたタブを開き直せます。
- 「＋」を押して、ターミナル・Claude Code・Codex CLI・Antigravity のどれを開くか選ぶ。⌘T は素のターミナルを直接開きます。使えない CLI は薄くなり、「未準備（設定で確認）」と出ます。
- タブをワークスペースの縁へドラッグして、最大 4 つまで並べて表示する。それぞれ 320 × 200 ポイント以上が必要で、境界線のドラッグで大きさを変えられます。ドラッグ中は「左に分割」「右に分割」「上に分割」「下に分割」「ここに表示」と、どこに入るかが出ます。
- ペインをクリックして入力する。日本語入力に対応し、変換中の文字はカーソルの位置に出ます。Shift+Enter で改行を入れ、Enter で送ります。
- ⌘F で出力の中を検索する(「スクロールバックを検索」)。Enter で次、⇧Enter で前、Esc で閉じます。「3 / 12」のように位置が出て、なければ「一致しません」と出ます。検索中の入力はエージェントには届きません。
- スクロールして過去の出力を読み、「最新へ」で一番下へ戻る。
- 出力中のパスを ⌘ か ⌥ を押しながらクリックして、内蔵エディタでその行を開く。URL はブラウザで開きます。普通のクリックはペインにフォーカスするだけです。
- パスを右クリックして「Operon で開く」「既定のアプリで開く」「Finder で表示」「パスをコピー」を選ぶ。`slides.pptx` のようなファイル名だけでも、フォルダの中にその名前のファイルが 1 つだけなら開けます。
- ポートのボタンから、URL を開く、コピーする、サーバーを止める(確認が出ます)。
- サイドパネルの「ファイル」「会話」「変更」と、セッション一覧を、ワークスペースの左右上下の縁に置き直す。見出しの「⠿」をドラッグします。
- アプリを再起動しても、タブとレイアウトが元のまま戻る。強制終了されたセッションは同じタブで自動復元されます。

## 今できないこと・既知の制約

- 分割は最大 4 つで、それより細かくなる分割は「これ以上分割できません」と断られます。
- アプリ内のスクロールバックは最大 5,000 行です(tmux は 50,000 行を持っています)。検索で見つけられる一致も最大 2,000 か所までです。
- 開けるパスは、そのセッションのフォルダの中で実在するファイルに決まるものだけです。同じ名前のファイルが複数あると、ファイル名だけの表記は開けません。macOS が許可を求めるフォルダ(書類など)の中は、セッション自身のフォルダでない限り探しません。
- ウィンドウが小さくて置けない縁は警告色の枠になり、パネルを置けません。ウィンドウを広げると置けます。ドラッグ中に Esc を押すか、中央で離すと取りやめになります。
- セッション一覧の列は、現在のコードでは左に固定され、ほかの縁には動かせません(取扱説明書にはグリップで動かせるとありますが、一覧の見出しにはグリップがありません)。
- すでに終了したセッションのターミナルは、「このセッションのターミナルは終了しているため、表示できる出力はありません。」と出て、出力は見られません。
- 順番待ちのセッションは、開始までは「開始待機中のため、まだターミナル出力はありません。」と出ます。
- 終了時にターミナルが正常に閉じたセッションは、同じタブで素のシェルに変わります。
- ポートの確認は 30 秒ごとです。

## 関連する変更

- 変更 014: 日本語入力(IME)を、カーソルの位置で入力できるようにした。
- 変更 226: セッションをペインの縁へドロップして、最大 4 つを並べて見られるようにした。
- 変更 145: サイドパネルを、1 つずつ左右上下の縁へ置けるようにした。
- 変更 146: 置けない縁には置けないと伝え、移動したときはその旨を知らせるようにした。
- 変更 255: ウィンドウを動かしている間に、全ターミナルが何度も描き直されないようにした。
- 変更 264: Shift+Enter で、送信ではなく改行が入るようにした。
- 変更 265: macOS が許可を求める保護フォルダを、勝手に探さないようにした。
- 変更 270: 再起動でタブ・分割・前面のタブを元に戻し、動いていたセッションを同じ場所へ再開するようにした。
- 変更 273: 「＋」で開始するものを選べるようにし、タブを詰めた。
- 変更 288: 終了したペインが固まらないようにし、強制終了を自動復元するようにした。
- 変更 290: 全角文字がカーソルで割れず、アクティブなとき塗りつぶされるようにした。
- 変更 293: パスを Operon の中で開く操作と、ファイル名だけの表記の解決、右クリックの 4 択を決めた。
