# 検索・操作 (⌘K)

## 何のための機能か

セッション、プロジェクト、ファイル、ファイル内のシンボル、よく使う操作を、1 つの入力欄から探して開く機能です。ページを探し回らず、キーボードだけで目的の場所に移れます。

## 誰がいつ使うか

- 動いているセッションが増えて、「あの依頼を頼んだセッション」に素早く戻りたいとき。
- プロジェクトのファイルや、開いているファイルの関数にすぐ飛びたいとき。
- 「新しいセッション」「設定を開く」などの操作を、メニューを辿らず実行したいとき。

## 画面のどこにあるか

⌘K、またはツールバーの 「検索・操作」 ボタン(キーが変わっていればそのキーも表示)で開きます。ウィンドウ上部の中央に、幅 520 の「検索・操作」ウィンドウが出ます。

- 一番上に入力欄「操作・セッション・プロジェクトを検索」があり、開くとすぐ入力できます。
- 下に結果の行が並びます。右端には、その操作に割り当てたキーが出ます。補足(状態・エージェント・プロジェクト、またはパス)は行の下に小さく出ます。

## 今できること

- 何も入力しない状態では、操作だけを一覧する。「新しいセッション」「履歴を開く」「プロジェクトを開く」「セッションを開く」「設定を開く」「プロジェクトフォルダを選択…」「ワークスペースをスキャン…」「キー割り当てファイルを開く」「空のターミナルを開く」「閉じたタブを開き直す」「アイドル中のエージェントへ送信…」。
- 入力すると、操作・セッション・プロジェクト・ファイル・シンボルから、大文字小文字を区別せず探す。
- セッションは、タイトル、依頼、エージェント名、branch、プロジェクト名、エージェントが最後に言った言葉で探せる。選ぶとそのセッションをターミナルで開く。
- プロジェクトは、名前とパスで探せる。選ぶとそのプロジェクトのページへ移る。
- 選んだプロジェクトのファイルを、ファイル名とパスで探せる(最大 16 件)。選ぶとエディタで開く。
- エディタで開いているファイルの `fn`・`struct`・`enum`・`trait`・`interface`・`class`・`type` を探せる(最大 8 件)。選ぶとその行で開く。
- 結果は、名前の先頭に一致するもの、単語の先頭に一致するもの、途中に含むものの順に並ぶ。同じ順位なら、操作、セッション、プロジェクト、ファイルの順で、同じ種類では待っているセッションが先、その次に新しいものが先になる。
- ↑↓ で選び、Enter で開く。行のクリックでも開く。Esc か ✕ で閉じる。

## 今できないこと・既知の制約

- 結果は 12 件までです。超えると「ほかに N 件あります。検索語を足してください。」と出ます。スクロールで全部を見る仕組みはありません。
- 何も入力していないときは、セッションやプロジェクトは一覧に出ません。
- ファイルの検索は、選んだプロジェクト(なければ最初のプロジェクト)のファイル一覧がすでに読み込まれているときだけ働きます。
- シンボルの検索は、エディタで開いているファイルだけが対象です。Rust・TypeScript/JavaScript・Python・Go などの先頭付近の定義が対象で、1 ファイル 64 件までです。
- 一致するものがないと「一致する項目がありません」と出ます。意味による検索ではなく、文字の一致だけです。
- 操作の一覧は固定で、増やしたり並べ替えたりはできません。
- 「閉じる」「前後のタブへ移る」などは、パレットの裏にあるタブに働くため、一覧には出しません。
- 起動のキーは「設定 → キー割り当て」のファイルで変えられます。変えると、ボタンと行の右端の表示も追従します。
