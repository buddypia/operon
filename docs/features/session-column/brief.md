# セッション一覧

## 何のための機能か

セッションページの左にある列です。プロジェクトごとに、いま開いているセッションを並べ、どれが待っていて、どれが動いていて、どれが空いているかを一目で分けます。状態や CLI で絞り込み、大事なものをピン留めし、好きな順番に並べ替えられます。

## 誰がいつ使うか

- 複数のプロジェクトで複数のエージェントを走らせている人が、次にどれを見るかを選ぶときに使います。
- 上のタブと同じ並びなので、タブを増やしたあと「どれがどれか」を整理するのにも使います。

## 画面のどこにあるか

- セッションページ(⌘3)の左端の列です。見出しは「プロジェクト」で、右に「履歴」ボタンがあります。
- 列の上に、状態のタイル「要対応」「実行中」「アイドル」(件数つき)があります。その下に CLI で絞るボタン(Codex・Claude Code・Antigravity・その他)が並びます。
- その下にプロジェクトの見出しが縦に並び、開いたプロジェクトの下にセッションの行が出ます。
- 各見出しには、開閉の矢印、プロジェクト名、状態ごとの件数、「セッションを開始」の「＋」があります。

## 今できること

- プロジェクトごとにセッションの行を見る。初めは全プロジェクトが閉じていて、矢印(「展開する」「折りたたむ」)で開閉します。開いたものは覚えていて、再起動後も開いたままです。新しく追加したプロジェクトは閉じた状態から始まります。
- 行の形は、エージェントの印と状態のしるし、ピン留めの印、題名です。ポインタを置くと題名・状態・実行中の時間・「ドラッグで並べ替え」が出ます。
- 行を押してセッションを開く。ターミナルが動いているセッションなら、キーボードがそのターミナルに入ります。
- 見出しの状態の件数を押して、その状態の最初のセッションを開く。
- 状態のタイルを押して、その状態のセッションだけに絞る。複数を同時に選べ、CLI のボタンとも組み合わせられます。絞り込み中は件数と「クリア」が出て、閉じているプロジェクトも一致した行を見せます。
- 行を右クリックして「名前を変更」「ピン留め」(外すときは「ピン留めを外す」)「閉じる」を選ぶ。行をダブルクリックしても名前を変えられます。
- ピン留めしたセッションは、列でもタブでも先頭に並び、閉じられません。
- 行やプロジェクト名をドラッグして順番を変える。列の上端や下端へ寄せると自動でスクロールし、Escape で取りやめられます。
- タブを並べ替えると、列の順番も同じになります。
- プロジェクト名を押して、そのプロジェクトを作業対象にする。名前をドラッグして、プロジェクトの順番も変えられます。
- 「履歴」を押して、中央を過去のセッションと会話の一覧に切り替える。

## 今できないこと・既知の制約

- 列に出るのは、いまタブが開いているセッションだけです。タブを閉じたセッションは「履歴」で探します。
- 並びは状態の順(待っている、実行中、アイドル)ではなく、ピン留め、手で並べた順、新しい順です(取扱説明書にある「待つ順に並べる」という書き方は、現在の動作とは異なります)。
- 待ち時間つきの「要対応」の行と返信欄は、列には並びません。履歴の一覧にあります。
- 状態と CLI の絞り込みは、再起動すると引き継がれません。
- ピン留めしたセッションは、行からも、タブからも、⌘W でも閉じられません。先にピン留めを外す必要があります。
- 行は同じプロジェクトの、同じピン留めの状態の行の間にしか並べ替えられません。
- 並び順・開閉・ピン留めを保存するファイル(session-order.json)が壊れている、または 1 MiB を超えるときは無視され、既定の並びに戻ります。保存に失敗すると「並び順を保存できませんでした」と出ますが、その起動中は効いています。
- プロジェクトがひとつもないときは「プロジェクトがありません」、絞り込みに合うものがないときは「一致するセッションはありません。」と出ます。
