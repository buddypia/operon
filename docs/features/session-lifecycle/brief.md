# 停止・再試行・再開

## 何のための機能か

エージェントのセッションを、状態に合った操作で止める・やり直す・続きから再開する・消すための機能です。
Operon を閉じたり、端末が落ちたりしても、tmux の中で動いていた作業を失わずに戻せます。

## 誰がいつ使うか

- 動いているエージェントを止めたいとき。
- 失敗した、または結果が分からなくなったセッションをやり直したいとき。
- 前回の会話の続きから作業を再開したいとき。
- Operon を再起動したあと、前回開いていたタブやセッションを元に戻したいとき。

## 画面のどこにあるか

- セッションページの左の列、セッション行の隅のボタン。
- 中央のターミナルのヘッダーにあるボタンと `···` メニュー。
- 行の ✕（セッションを削除）。

ボタンは状態に合う操作を 1 つだけ表示します。

- 実行中: 「停止」。停止の完了待ちの間は「停止中…」になり、もう一度押すと停止をやり直します。
- 順番待ち: 「今すぐ開始」。
- 失敗・結果不明で、保存された会話がない: 「再試行」。
- 失敗・結果不明・終了・停止で、保存された会話がある: 「会話 ID から再開」。ホバーすると引き継がれるモデル・モード・スイッチが出ます。

## 今できること

- 実行中のセッションを「停止」できます。記録は残り、履歴から開けます。
- 停止が終わらない間は「停止中…」と表示され、もう一度押すと再試行します。
- 古いターミナルを安全に確認して片付けてから、「再試行」でもう一度実行できます。まだ動いているターミナルは片付けず、判定できないときも先へ進みません。
- 保存された会話がある失敗・終了・停止のセッションは、「会話 ID から再開」で同じ会話から続けられます。起動時のオプションも引き継がれます。
- 「ほかのセッションの後に開始」で順番待ちにしたセッションは、先行セッションの完了後に自動で始まります。「今すぐ開始」で先に始めることもできます。
- セッションを「名前を変更」「未読にする」できます。
- 行の ✕ から「セッションを削除」できます。動いているものは先に停止し、「実行中のセッションを削除しますか？ 停止後に一覧から取り除きます。」と確認します。ファイルと worktree は消えません。
- 終了・失敗したセッションに残ったターミナルを「ターミナルを閉じる」「残ったターミナルを閉じる」で片付けられます。
- タブを閉じる（✕ または ⌘W）と画面から外れるだけで、エージェントは動き続けます。⇧⌘T で開き直せます。
- Operon を再起動すると、タブ・分割・前面のタブ・選んでいたセッションが元に戻ります。
- 前回の終了時に動いていて、いまターミナルが無くなっているセッションは、同じタブで自動的に再開されます。会話のある CLI はその会話を開き、ふつうのターミナルはシェルを開き直します。「前回開いていたセッションを N 件再開しました。」と知らせます。
- 動作中に強制終了・異常終了したセッションも、同じタブで自動復元されます。
- 正常終了（status 0）したターミナルや CLI は、同じタブ・同じフォルダでログインシェルとして使い続けられます。

## 今できないこと・既知の制約

- 15 秒以内に続けて落ちたセッションは自動復元しません。「要対応」に残るので、手で「再試行」または「再開」を選びます。
- 保存された会話が無い、または空のセッションは自動復元されません。手動の「再試行」「再開」になります。会話の記録が無いまま再開した場合は、新しい会話として始めます。
- 自分で指定したカスタムコマンドのセッションは、前回起動時の自動再開の対象外です。
- 前回すでに止めていたもの、正常終了したもの、取り消したものは、再起動で再開しません。
- 前提のセッションが失敗した順番待ちは、止まったままで自動では始まりません。
- 動いているターミナルがあるセッションの「再試行」は拒否されます。先に古いターミナルを停止してください。
- タブとワークスペースの配置の保存は 2 秒ごとです。壊れている、または大きすぎる（1 MiB 超）保存ファイルは、読める部分だけを戻します。

- 変更 045: 再開の前に会話の記録を確かめ、空ならば新規開始に切り替え、途中で切れた最終行は整えてから再開する。
- 変更 270: 再起動で、タブ・分割と、動いていたセッションを同じ場所に戻す。ターミナルで CLI を動かすと、そのセッションが CLI のものとして扱われる。
- 変更 288: 正常終了してもペインを閉じず、ログインシェルとして残す。強制終了や異常終了は同じタブで自動復元する。
- 変更 291: 15 秒の連続クラッシュ制限を入れ、「終了」と「アイドル」の見え方を分けた。
- 変更 123: tmux に接続できなくてもセッションを削除できるようにした。
- 変更 160: 2 つ目の端末が確保できなくても起動が失敗しないようにした。
- 変更 156: 起動時に自分の引数や再開する会話 ID を指定できるようにした。
- 変更 027: 再起動しても起動時のオプションを落とさない。
- 変更 303: ターミナルが消えたときに出力エラーを繰り返さず、取り込んだ CLI ターミナルも会話を取り戻して再開できる。
- 変更 305: 再起動のあとも CLI タブの印が消えない。
