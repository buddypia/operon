# キー割り当て

## 何のための機能か

Operon のショートカットを一覧で確認でき、好みのキーに変えられるようにする機能です。
画面に表示されるキー（検索・操作の右側など）は、実際に反応するキーと必ず同じものです。

## 誰がいつ使うか

- 「このショートカットは何だったか」を確認したいとき。
- 他のアプリと同じ手の動きにそろえたい、または押しにくいキーを別のキーに変えたいとき。
- 使わないショートカットを無効にしたいとき。

## 画面のどこにあるか

「設定」の左の一覧から「キー割り当て」を選びます（⌘, で設定を開けます）。
操作名とそのキーが 2 列で並び、キーを割り当てていない操作には「なし」と出ます。
下の「キー割り当てファイルを開く」から、変更用のファイルを用意できます。
検索・操作（⌘K）の各行の右にも、現在のキーが表示されます。

## 今できること

- 次の操作のキーを確認できる（初期値）。
  - 「検索・操作を開く」⌘K / 「新しいセッション」⌘N / 「次の要対応セッションへ」⌘J
  - 「ホームを開く」⌘1 / 「プロジェクトを開く」⌘2 / 「セッションを開く」⌘3 / 「設定を開く」⌘,
  - 「プロジェクトフォルダを選択…」⌘O / 「ターミナル内を検索」⌘F / 「サイドパネルを開閉」⌥⌘B
  - 「空のターミナルを開く」⌘T / 「タブを閉じる」⌘W / 「閉じたタブを開き直す」⇧⌘T / 「次のタブへ」⇧⌘] / 「前のタブへ」⇧⌘[
- 「キー割り当てファイルを開く」を押すと、初回は現在の初期値を書き込んだ keybindings.json を作り、データフォルダを Finder で表示する。作成後は「キー割り当てファイルを作成しました。」と通知される。
- すでにファイルがあれば上書きせず、場所だけを開く（「キー割り当てファイルの場所を開きました。」）。
- ファイルに操作の ID とキーを書くと、その操作だけが変わる。書かなかった操作は初期値のまま。
- キーは「Mod+K」「Mod+Shift+F」のように、Mod（⌘）・Shift・Alt・Ctrl と 1 つのキーを「+」でつないで書く。
- `null` を書くと、その操作はキーなしになる（その操作のショートカットは効かなくなる）。
- 書き方が正しくないときは、通知に理由が出る。「JSON として読めません。」「「…」という操作はありません。」「「…」はキーの書き方として読めません。」「⇧⌘P が「…」と「…」で重複しています。」など。
- ⌃Tab（次のタブ）と ⌃⇧Tab（前のタブ）は、ブラウザと同じように常に使える。
- ⌘T や ⌘W などの ⌘ キーは、ターミナルの中にいても Operon が受け取り、エージェントには届かない。

## 今できないこと・既知の制約

- キーの変更は設定画面ではできません。ファイルを直接編集します。
- ファイルは起動時に読み込むため、書き換えたあとは Operon を起動し直すまで反映されません。
- ファイルに誤りが 1 つでもあると、ファイル全体が無視され、すべて初期値で起動します（一部だけ反映されることはありません）。1 つのキーを 2 つの操作に割り当てた場合も同様です。
- 変更できるのは上の 15 の操作だけです。ターミナルの中のキー、検索・操作の矢印・Enter・Esc、⌘↩（セッションを起動）、Esc（シートを閉じる）、⌘S（保存）、⌃Tab、⌃⇧Tab、クリック系の操作は固定です。
- 1 つの操作に割り当てられるキーは 1 つだけです。連続した 2 回押しや、複数キーの連続入力は使えません。
- キーに使える文字は A〜Z、0〜9、「, . / ; [ ] \ - = ' `」、Space、Tab、Enter までです。矢印キーや F キーは指定できません。
- ファイルが 64 KiB を超えるか、文字として読めないときも、初期値で起動して通知されます。
- 新しいセッションの入力中や、全員への送信の入力中は、検索・操作や ⌘1〜3 などのページ移動は反応しません（入力中の文章を失わないため）。
- 以前のマニュアルには操作 ID が 10 個しか載っていませんが、実際にはタブの操作 5 個（tab.new、tab.close、tab.reopen、tab.next、tab.previous）も変更できます。
