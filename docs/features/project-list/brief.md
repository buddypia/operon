# プロジェクトの追加と一覧

## 何のための機能か

手元のフォルダを「プロジェクト」として Operon に登録し、一覧から開けるようにします。
プロジェクトはエージェントを動かす場所の単位です。登録してもフォルダの中身は変わりません。
初めて起動したときは、最初のセッションを始めるのに足りない準備を案内します。

## 誰がいつ使うか

- 初めて Operon を起動した人が、最初のフォルダを選ぶとき。
- 新しい作業フォルダや、複数のリポジトリをまとめて置いたフォルダを取り込みたいとき。
- 使わなくなったプロジェクトを一覧から外したいとき。

## 画面のどこにあるか

ツールバーの「プロジェクト」ページ（⌘2）です。

- プロジェクトが 1 つもないときは「まずはプロジェクトを開いてください」と大きく出て、
  その下に「最初のセッションを始める前に」のチェックリストが並びます。
- 1 つ以上あるときは、見出し「プロジェクト」の右に「フォルダを選択…」と「ワークスペースをスキャン…」があり、
  その下に登録順（新しいものが上）でカードが並びます。
- ページの下の「パスを手入力」を開くと、絶対パスを書いて追加できる欄が出ます。
- 「フォルダを選択…」を押すと「プロジェクトフォルダを開く」シートが開きます。上にパスの入力欄、
  その下に今いるフォルダと、その中のフォルダの一覧があります。

## 今できること

- 「フォルダを選択…」（⌘O）で「プロジェクトフォルダを開く」シートを開き、フォルダを選んで追加する。
  - パスを入力する（`~` も使えます）。入力に合うフォルダが一覧に絞り込まれ、Tab で名前を補完できます。
  - 一覧の行をクリックして中のフォルダへ、↑ で上のフォルダへ移る。
  - 「開く」（Enter）で、入力欄のフォルダをプロジェクトとして追加する。
  - まだ無いパスを入力すると「フォルダを作成…」になり、「作成して開く」で確認すると空のフォルダを作って追加する。
  - 「Finder で選ぶ…」で、これまでどおり macOS の選択ダイアログを使う。
- Finder からフォルダをウィンドウへドラッグして追加する。複数まとめてドロップすると、追加できた件数を知らせます。
- 「ワークスペースをスキャン…」で選んだフォルダの 3 階層下までにある Git リポジトリをまとめて取り込む。
  取り込んだ件数を知らせ、すでに登録済みのものは飛ばします。
- 「パスを手入力」から、プロジェクトのパスとワークスペースのパスをそれぞれ入力して追加・スキャンする。
- すでに登録済みのフォルダを追加しようとすると、重複せずにそのプロジェクトを開く。
- カードをクリックしてプロジェクトを開く（開くと「概要」タブから始まります）。
- カードの右端の外部リンクのアイコン、または右クリックの「Finder で表示」で Finder を開く。
- カードの「×」または右クリックの「プロジェクトを削除」で削除を始める。
  「「名前」を Operon から削除しますか？」と確認が出て、「Operon から削除」で確定、「キャンセル」で取りやめ。
  消えるのは Operon の記録だけで、ファイル・ブランチ・worktree は残ります。
- 初回の案内で、tmux とコーディングエージェント（Codex・Claude・Antigravity のどれか）が足りているかを確かめ、
  足りなければ「セットアップ手順を開く」から設定のエージェントページへ進む。

## 今できないこと・既知の制約

- 実行中・順番待ち・起動中の状態が不明なセッションがあるプロジェクトは削除できません。
  「実行中のセッションを停止または完了してください。」と出ます。
- そのプロジェクトで worktree の作成・削除・マージが進行中のときも削除できません。
- 削除すると、そのプロジェクトのセッションの記録（Operon が持っているもの）も一緒に消えます。
  ディスク上のファイルや tmux の外にある内容は消えません。
- ファイルはプロジェクトとして追加できません。シートでは「これはフォルダではありません。」と出て「開く」を押せません。
  存在しないパスは、シートで確認すればフォルダを作って追加できます（作るのは空のフォルダだけで、Git の初期化はしません）。
- シートに入力できるのは `/` か `~` で始まるパスだけです。
- 一覧に出るのはフォルダだけで、1 つのフォルダにつき先頭の 5,000 件までを読みます。届いたときはその旨を知らせ、
  パスを最後まで入力すれば開けます。`.` で始まるフォルダは、`.` から入力したときだけ出ます。
- デスクトップ・書類・ダウンロードなどのフォルダへ進むと、macOS がアクセスの許可を尋ねることがあります。
- ワークスペースのスキャンは 3 階層までで、Git リポジトリが見つかったフォルダの中には入りません。
  シンボリックリンクと `.git`・`node_modules`・`target`・`.next` は見ません。
  調べる数に上限があり、届いたときは「一部のフォルダは省略されている可能性があります」と知らせます。
- スキャンは一度に 1 つだけです。実行中にもう一度押すと「ワークスペースのスキャンは実行中です。」と出ます。
- Git リポジトリでないフォルダも手動なら追加できますが、変更・worktree・PR のタブは Git の無いフォルダでは使えません。
- 保存に失敗したときは追加を取りやめ、記録を元に戻します。
