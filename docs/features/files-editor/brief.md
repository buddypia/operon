# ファイルとエディタ

## 何のための機能か

プロジェクトのファイルを Operon の中で読み、必要なら直すための機能です。エージェントが書き換えたファイルを、別のアプリに切り替えずに確かめられます。

エージェントは作業ツリーを常に書き換えます。そのため、開いているファイルがディスク上で変わるのは普通のことです。この機能は、人の編集もエージェントの書き込みも黙って上書きしないことを守ります。

## 誰がいつ使うか

- エージェントが書いた設計メモや Markdown、ソースを読んで確かめたいとき。
- 小さな直しを自分で入れたいとき。
- ターミナルに出たファイルのパスを、行番号つきでその場で開きたいとき。

## 画面のどこにあるか

プロジェクトの詳細にある「ファイル」タブです。左に折りたためるファイルツリー、右にエディタが並びます。

- ツリーの上に「ファイルを絞り込む」入力欄と、読み直しボタンがあります。変更のあるファイルには A・M・D・R・U の Git バッジが付きます。
- エディタの上にファイルごとのタブが並び、その下に表示の切り替え「編集」「プレビュー」「差分」「注釈」があります。
- 右上に「既定のアプリで開く」「外部エディタで開く」「エージェントに送る」、読み直し、「保存」(⌘S) があります。

## 今できること

- 折りたためるツリーでファイルを選び、タブで開く。ツリーの `.git`・`node_modules`・`target`・`.next` は表示されない。
- 行番号とシンタックスハイライト付きで編集し、⌘S で保存する。Rust、TypeScript、Python、Go、シェル、JSON、TOML、YAML、Markdown など主な形式を色分けする。
- Markdown を整形して表示する(見出し、表、チェックボックス ☐ ☑、取り消し線、言語つきコードブロックの色分け)。
- 128 KiB を超え 8 MiB までのテキストは、「表示」という読み取り専用のビューで開く。長い行は折り返して表示する。
- 10 MiB までの画像(PNG など)をプレビューする。
- ディスク上で開いたあとに変わったファイルを、約 2 秒ごとに見つける。未保存の編集がなければ自動で読み直し、「…はエディタの外で変更されたため、読み直しました。」と知らせる。
- 未保存の編集があるときは、「このファイルはエディタの外で変更されました。保存すると、その変更を上書きします。」のバーを出し、「読み直す」か「差分を見る」を選ばせる。
- 開いたあとに変わったファイルへの保存は断る。「このファイルは開いたあとに変更されています。上書きすると、その変更が失われます。再読み込みしてください。」と表示する。
- 保存してもファイルの実行権限(権限ビット)は変わらない。
- 「外部エディタで開く」で VS Code、Cursor、Zed、Windsurf、Antigravity、Void、Finder から選んで開く。
- 「エージェントに送る」で、開いているファイルの抜粋を、そのプロジェクトで動いている最新のエージェントへ送る。動いているものがなければ、新しいセッションの依頼に入れる。
- ワークツリーのセッションから開いたファイルには、タブにブランチ名が付く。

## 今できないこと・既知の制約

- 128 KiB を超えるファイルは編集できません。8 MiB を超えるファイルは開かず、「既定のアプリで開く」を案内します。
- 画像は 10 MiB までです。それを超えるものと、読み込めない画像は開けません。
- バイナリファイルと UTF-8 でないファイルは開けません。
- ツリーに出るファイルは 12,000 件までです。超えると「一部のファイルは省略されています」と表示し、フォルダでの絞り込みか外部エディタを勧めます。
- 画像と、ワークツリーから開いたファイルには「差分」「注釈」がありません。
- ディスク上で読めなくなったファイルについては、2 秒ごとの確認は何も表示しません。保存しようとしたときにエラーになります。
- 読み取り専用の「表示」は Markdown でもソースのまま表示し、「プレビュー」は出ません。
- 一度「開けない」状態になったファイルが開けるようになっても、自動では読み直されません。読み直しボタンを押してください。

- 変更 005: 主要な言語のシンタックスハイライトと、Markdown のプレビュー・差分の表示を入れた。

- 変更 034: 開いた文書が自分の「ルート」を持つようにし、ワークツリーのファイルを同じパスのプロジェクトのファイルと取り違えないようにした。
- 変更 076: ターミナルのパスから開く操作と、画像のプレビューを追加した。
- 変更 232: セッションのファイルを開いても、セッションの画面から出ないようにした。
- 変更 235: 128 KiB を超えるテキストを、8 MiB まで読み取り専用で見られるようにした。
- 変更 261: 「エージェントに送る」、ファイルとシンボルへの移動など、エージェントと往復する操作を足した。
- 変更 293: ターミナルに出たパスや、ファイル名だけの表記も Operon の中で開くようにした。
- 変更 307: ファイルを過去の版と比べたり、「注釈」で並べて読んだりできるようにした。
