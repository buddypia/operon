# エージェント間の連携 (Operon agents)

## 何のための機能か

Operon の中で動いているエージェントが、同じプロジェクトにいる他のエージェントを見つけ、様子を読み、
指示を送り、終わるのを待てるようにします。人が間に入らなくても、役割を分けた複数のエージェントが連携できます。
もう一つ、人が「アイドル中のエージェント」にまとめて 1 行を送る機能もあります。

## 誰がいつ使うか

- エージェント自身が、ほかのセッションに作業を頼みたいとき。コマンドは `Operon agents` です。
- 人が、手の空いている複数のエージェントに同じ指示を一度に伝えたいとき。

## 画面のどこにあるか

- コマンドは画面ではなく、セッションの中のターミナルから使います。管理下のセッションでは実行ファイルの場所が環境変数に入っています。
- 一斉送信は、コマンドパレット（⌘K）の「アイドル中のエージェントへ送信…」から開く小さなシートです。

## 今できること

- 一覧: 同じプロジェクトのセッションを、ID・状態・エージェント・branch・名前つきで表示します。自分自身には「(自分)」が付きます。`--json` で機械向けの形にもできます。
- 読む: 相手のターミナルの末尾を読みます。行数は 1〜200（既定 40）です。
- 送る: 相手に 1 行と Enter を打ち込みます。送れるのは、ターンを終えたエージェント、またはまだ最初の依頼を受けていないエージェントだけです。
- 待つ: 相手が「アイドル」「要対応」のどちらか（または指定した方）になるまで待ちます。秒数は 1〜3600（既定 600）です。
- 相手の指定は、一覧に出る 8 文字の ID か、1 つに決まる 4 文字以上の前方一致です。
- 一斉送信のシートには、このプロジェクトでターミナルが動いていて、ターンを終えた（または未開始の）エージェントがチェックボックス付きで並びます。
  - 開いた時点ではどれも選ばれていません。「すべて選択」「選択を解除」があります。
  - 1 行入力して Enter を押すと、チェックを入れたセッションにだけ届き、「{n} 件のエージェントに送信しました」と知らせます。
  - 開いている間にアイドルになったセッションは、未選択のまま加わります。
- Operon が見ている状態を、起動中は変化があったときと 15 秒ごとにファイルへ書き出し、それをコマンドが読みます。終了時にはファイルを消します。

## 今できないこと・既知の制約

- 見えるのは、呼び出し元と同じプロジェクトのセッションだけです。
- 作業中、許可や回答の待ち、終了したエージェントには送りません。送る直前に画面をもう一度確かめ、作業中や確認待ちに見えれば送りません。
- 自分自身には送れません。
- 改行や制御文字を含む内容は送れません。内容は 4,000 文字までです。
- 一斉送信は、作業中や待ち中のエージェントには、チェックを入れていても届きません。
- 60 秒より古いファイルは「Operon が起動していない」扱いで、コマンドは取得できないと答えます。
- これらの制限は誤操作を防ぐためで、安全の境界ではありません。コマンドは自分のセッションとフォルダを自分で名乗ります。エージェントに送信を許可すると、そのエージェントは同じプロジェクトの他のエージェントに、相手の権限のまま指示できます。
- 終了コード: 0 完了、1 tmux の失敗、2 セッションがない・プロジェクトではない・終了した、3 Operon が起動していない、4 待機のタイムアウト、5 相手が作業中、64 使い方の誤り。

## 関連する変更

- 変更 309: エージェントが同じプロジェクトの他のエージェントを一覧・閲覧・送信・待機できるコマンドを追加した。
- 変更 282: アイドル中のエージェントへ、シートから 1 行を一度に送れるようにした。
- 変更 306: 一斉送信は、人が選んだセッションにだけ届くようにした（開いた時点では誰も選ばない）。
- 変更 308: 最初の依頼をまだ受けていない「未開始」のエージェントも、送信先と待機の対象にした。
- 変更 281: 待っているエージェントの数を Dock のアイコンに出す。
- 変更 279: 待っているエージェントに、行から返信できる。
- 変更 258: プロジェクトで起動したエージェントに、そのプロジェクトのナレッジの存在を知らせる。
- 変更 241: 任意コマンドに改行を含められないようにした。
