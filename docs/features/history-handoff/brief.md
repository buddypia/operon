# 履歴と CLI をまたぐ Handoff

## 何のための機能か

Claude Code・Codex CLI・Antigravity が手元に残した過去の会話を見つけて、元の CLI で再開したり、
別の CLI（または同じ CLI の新しい会話）に引き継いだりします。引き継ぎは Operon が保存済みの記録を読んで
要点をまとめるだけで、モデルは動かさず、トークンも消費しません。

## 誰がいつ使うか

- 前回の続きを、保存された会話から再開したいとき。
- 作業の途中で別の CLI に切り替えたいとき（たとえば Claude Code の途中経過を Codex に渡す）。
- 過去の会話を言葉で探したいとき。

## 画面のどこにあるか

- セッションページの左の列の「履歴」。押すと中央が過去のセッションや会話に切り替わります。
  - 「CLI セッション（過去の会話の検出と復元）」: プロジェクトを選び、「ローカル CLI セッションを検出」を押します。
  - 「ローカル履歴」: 最近の Codex と Claude の記録を全文検索します。
- セッション行の `···` メニューの「〈エージェント名〉 へ Handoff」。引き継ぎ先にモデルや推論の深さを設定していると、項目にそれが出ます。

## 今できること

- 「ローカル CLI セッションを検出」で、そのプロジェクトの Claude Code・Codex・Antigravity の過去の会話を一覧にします。各カードには会話の ID・branch・最後の依頼が出ます。
- 各カードから次のどちらかを選べます。
  - 「元の CLI で再開」。
  - 「復元先」を選び、必要ならモデルと推論の深さ（CLI ごとに記憶されます）と「Handoff メモ（任意）」を入れて、「Handoff バンドルで引き継ぐ」。同じ CLI を選ぶと「〈エージェント名〉（同じ CLI に複製）」となり、元の会話に影響を与えずに 2 つ目の会話が始まります。
- 引き継ぎの間は、元の会話・引き継ぎ先・経過時間のウィンドウが出ます。バックグラウンドへ回すこともできます。
- Handoff バンドルには、最初の依頼、直近の User / Assistant のやり取り（最大 8 件、1 件 1,200 文字まで）、最後のツール結果 3 件（1 件 1,000 文字まで、エラーは残す）、あなたのメモが入ります。全体は 6,000 バイトまでです。足りないときは古いやり取りから落とし、あなたのメモは最後まで残します。
- ツール結果が会話として扱われることはありません。推論は引き継がれません。
- 引き継ぎのたびに、元の会話のコピーと、渡した内容、記録の情報が「共有セッションアーカイブ」に保存されます。変わっていない会話をもう一度引き継ぐと、そのコピーとメモを再利用します。進んだ会話は新しくコピーします。
- 7 日間どの引き継ぎにも使われなかったアーカイブは、次の起動時または次の引き継ぎ時に削除されます。
- アーカイブは、あなたのアカウントだけが読める権限（フォルダ 0700、ファイル 0600）で作られます。
- 「ローカル履歴」の検索で、一致した会話を見つけられます。「セッションを検索」ではセッション行に見える言葉（名前・依頼・CLI 名・プロジェクト名・branch）で絞り込めます。
- 記録の中に種類の分からないものがあっても、会話の一部として引き継ぎ、その件数を知らせます。

## 今できないこと・既知の制約

- 引き継ぎ先 CLI の保存領域には何も書きません。引き継ぎ先は、バンドルを最初のメッセージとして新しいセッションを自分で始めます。
- 推論（考えた過程）は引き継がれません。
- 古い会話は全部ではなく要点だけです。全文は元のコピーにあり、バンドルにその場所が書かれます。
- 検出で出るのは 1 回に 80 件までです。検索は 1 回 50 件まで、走査量にも上限（約 64 MiB、50 万行）があり、超えたときは「一部の履歴は省略されています」と知らせます。
- 検索は書かれた言葉の一致が基本です。意味での検索は、ナレッジが有効なプロジェクトの「意味で一致」だけです。
- アーカイブには、機密性のある依頼・ツール出力・ソースコードが含まれることがあります。
- 読めない履歴ファイルは復元できず、その旨が出ます。

## 関連する変更

- 変更 003: 記録の種類ごとに「引き継ぐ・外す」を表にし、半分以下しか引き継がなかった復元を直した。
- 変更 061: 名前の分からない記録を黙って落とさず、会話として引き継ぎ、件数を知らせる。
- 変更 004: ターミナルが今いる会話を、Claude Code 自身の記録から読み、古い会話を取り違えない。
- 変更 045: 再開の前に保存された会話を確かめ、壊れた末尾を整える。
- 変更 179: 引き継ぎを、コンパクトな Handoff バンドルと元の会話のコピーに切り替えた。引き継ぎ先の保存領域は変えない。
- 変更 180: 引き継ぎ先のモデルと推論の深さを選べ、変わっていない会話はコピーとメモを再利用する。7 日で期限切れ。
- 変更 185: 長い引き継ぎでも、あなたの指示を残し、切った場所を示す。
- 変更 187: 切り詰めた印を途中で分断しない。
- 変更 193: ツールが見つけた結果を引き継ぎ、会話として混ぜない。
- 変更 310: セッション検索が行に見える言葉に一致し、履歴検索の「一致なし」は検索が終わってから出す。
- 変更 159: Antigravity の復元でツール出力を運ぶ。
- 変更 172: 復元した会話を Antigravity が見つけられるようにした。
