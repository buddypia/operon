# 設定

## 何のための機能か

見た目、表示言語、エージェントを動かすための準備、通知、手元データの置き場所と復旧、ショートカットの一覧を、一つの画面にまとめて確認・変更できるようにする機能です。
特に、tmux やエージェントの CLI が見つからないときに「何が足りないか」と「直し方」をここで示します。

## 誰がいつ使うか

- 初めて起動した人が、テーマや言語を自分好みに変えるとき。
- セッションを起動しようとして「ツールが見つからない」と言われ、設定のエージェントへ飛ばされたとき。
- Codex や Claude Code を仕事用・個人用など複数のログインで使い分けたいとき。
- 通知のオン・オフを変えたいとき、データの場所を Finder で開きたいとき。
- Operon の外で消えてしまった tmux セッションを探し直したいとき。

## 画面のどこにあるか

ツールバーの歯車、⌘,、または検索・操作の「設定を開く」で開きます。
左に 5 つのセクション（「外観」「エージェント」「通知」「データと復旧」「キー割り当て」）が並び、選ぶと右側にその内容が出ます。
「エージェント」の横には、準備ができていれば「準備完了」、足りないものがあれば「要対応」と表示されます。
ツールが足りないせいで設定に飛ばされたときは、最初から「エージェント」が開きます。それ以外の開き方では、前回見ていたセクションが開きます。

## 今できること

- 「外観」: 「テーマ」をダーク（既定）・ライト・ハイコントラスト（ダーク）から選ぶ。色見本が横に出て、開いているターミナルの配色にも反映されます。
- 「外観」: 「ターミナルとコードのフォント」を Sarasa Mono J / Sarasa Mono K / Sarasa Term J / Sarasa Fixed J から選ぶ。
- 「外観」: 「言語」を English・日本語・한국어 から選ぶ。すぐ切り替わり、保存されます。初回はシステムの言語から自動で選ばれ、判定できなければ日本語です。
- 「エージェント」: 「ツール」の行で tmux、Codex CLI、Claude Code、Antigravity CLI (agy)、Git、GitHub CLI の有無を確認できる（「n/6 使用可能」）。「ツールを再確認」で PATH を調べ直す。
- 「エージェント」: 見つからない CLI には「導入手順」ボタンが出て、公式のセットアップページを開く。tmux が無いときは「brew install tmux」が表示される。
- 「エージェント」: 「エージェント CLI のフックで状態を検知する」のオン・オフと、「初回起動時のフォルダ信頼プロンプトを自動承認する」のオン・オフ。フックの状態は「フック 導入済み」「フック 未導入」「フック 失敗」で表示される。
- 「エージェント」: 「エージェントのアカウント」に、Codex / Claude Code のログイン情報フォルダを名前付きで登録・削除する（「フォルダを選んで追加」）。登録すると、セッション起動時にアカウントを選べます。
- 「通知」: 「ターンの完了・入力待ち・終了を通知する」のオン・オフ。オンにすると macOS の通知許可を求めます。
- 「データと復旧」: データフォルダの場所の表示と、Finder で開く「データフォルダを表示」。「tmux をスキャン」で記録から漏れた tmux セッションを探し、「セッションを引き継ぐ」で登録済みのプロジェクトに結び付ける。
- 「キー割り当て」: ショートカットの一覧と「キー割り当てファイルを開く」（詳しくは「キー割り当て」の機能）。

## 今できないこと・既知の制約

- 変更を保存できなかったときは、画面の値が元に戻り、「データを保存できませんでした。直前の変更は適用されていません」と通知されます。
- 英語・韓国語を選んでも、まだ翻訳されていない文言は日本語のまま表示されます。
- テーマやフォントの種類は決まった候補から選ぶだけで、色や文字サイズを自分で細かく指定することはできません。
- アカウントはフォルダを選んで登録する方法だけです（パスの手入力はできません）。Antigravity にはアカウントの仕組みがありません。
- アカウントの中身（ログイン情報）は Operon は読みません。アカウントを削除してもフォルダ自体と、そこに入れた管理フックは残ります。
- 同じフォルダを二重に登録することと、同じエージェントで同じ名前を付けることはできません。名前が空でも登録できません。
- 登録したフォルダが後で無くなると、そのアカウントでの起動は「アカウント「…」のフォルダが見つかりません。」で断られます。
- 「tmux をスキャン」で見つかったセッションは、その作業フォルダを含むプロジェクトが登録されていないと引き継げません。
- 意味検索のモデルの取得・削除は「データと復旧」にありますが、ナレッジの機能として別に扱います。
