# Intent: Find the current session and create a terminal quickly

- **Status**: draft

## Problem

The user reports: 「左のサイドバーにセッションのタブ名にも今アクティビティセッションがなんなのかわかるUIにして。タブのセッション名が無駄に大きい。セッションリストの一番右に+ボタンなど用意してすぐターミナルを生成できるようにして」

While switching between several terminals, the selected sidebar row is almost indistinguishable from its surroundings. Large fixed-width tab labels waste horizontal space. Starting another terminal requires leaving the tab strip.

## Who feels it, and when

The person monitoring sessions in the existing Sessions workspace, especially with several sessions in the same project.

## Success

Selection is visible in the sidebar and tabs, names take less space, and a persistent right-edge plus creates a plain terminal in the active project and working directory.
