# Screen delta: ターミナルのカーソル枠 — 155 の四状態を保ったまま、
# 枠が出る場所の条件を2点だけ引き締める

変更 155 が承認した画面（docs/sdlc/changes/155-terminal-caret-drifts-below-its-row/screen.md）
の四状態はそのまま:

- フォーカス中: 枠は tmux と同じセル
- IME 変換中: 下敷きと候補ウィンドウの rect は caret のセル
- スクロールして caret 行が見えない: 枠なし
- 待機中 (IME なし): 枠なし

本変更が引き締めるのは「見えないはずの枠が見えてしまう」例外2つで、
どちらも上の状態の言う通りに直る:

## Before (欠陥)

    +-- ターミナル ----------------------------+
    | ... (ペインの最下行までスクロール済み) ... |
    | > 出力の最終行                            |
    +==========================================+ <- ペイン下端
    |[cursor]  <- spare row の枠がパディングと   |
    +------------------------------------------+    検索バー行にはみ出る

    (リサイズでペインが細くなった直後)
    +-- ターミナル ------+
    | > ...        |cursor] <- 枠が枠線の右に描かれる
    +--------------------+

## After

    +-- ターミナル ----------------------------+
    | ... (ペインの最下行までスクロール済み) ... |
    | > [cursor] 出力の最終行                   |
    +==========================================+ <- 枠はペイン内だけ
    +------------------------------------------+

    (リサイズ直後、caret 列が今の幅に収まらない間は)
    枠を描かない — 次の capture で caret が分かったら出る

## ルール (変更なし、適用を厳密に)

枠は「このフレームが実際に描いた行」にだけ乗る。見えない行に浮かんだ枠は
残さない — spare row (ビューポート下端の +1 行) と、今のペイン幅に収まら
ない列は、どちらも「見えない/本来のセルではない」ので枠なし。

(ラウンド 1 のレビューで追加) 下端以外にも同じ原則が効く: 上端に半分だけ
見えているセル (検索ジャンプやドラッグの行に合わないオフセットで起きる)
も「セル全体が見えていない」ので枠なし。155 は半セルの枠を描いたが、
「セル全部、かつ本来のセル、または無し」に統一する。
