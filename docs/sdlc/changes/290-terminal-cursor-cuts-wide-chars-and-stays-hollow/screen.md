# Screen: terminal block cursor on narrow and wide glyphs, focused and unfocused

セッションのターミナルペイン, 760px幅 (`Sarasa Mono J` 15px, 1セル = `cell.x`, 全角 = `2 * cell.x`):

```
Before (フォーカス時のみ半透明の1セル枠線・塗りなし / 非フォーカス時は非表示)
┌─ ターミナル (フォーカス中・ダーク #0A0C10) ───────────────────────── 760px ─┐
│ $ echo hello                                                                │
│   英文上のカーソル (x=2, 'e'):     $ [e]llo       ← 1セル枠のみ・背景塗りなし │
│   日本語・4Byte文字上 (x=2, 'あ'): $ [あ)いう𠮷   ← 左半分(1セル)しか重ならない │
│   行末の空セル (x=12):             $ echo あ𠮷▯   ← 細い半透明枠のみ          │
└─────────────────────────────────────────────────────────────────────────────┘
┌─ ターミナル (非フォーカス・分割ペイン反対側) ─────────────────────── 760px ─┐
│ $ echo あいう𠮷                    (カーソル非表示 — 位置が分からない)       │
└─────────────────────────────────────────────────────────────────────────────┘

After (業界標準: 全角2セル幅追従 + フォーカス時は前景色ブロック反転 / 非フォーカス時は1px中抜き枠)
┌─ ターミナル (フォーカス中・ダーク: 背景 #0A0C10 / カーソル塗 #CED4DE / 反転字 #0A0C10) 760px ─┐
│ $ echo hello                                                                                  │
│   英文上のカーソル (x=2, 1セル幅):       $ █e█llo        ('e' が1セル塗ブロック内で反転表示)   │
│   日本語・4Byte文字上 (x=2, 2セル幅):    $ ██あ██いう𠮷  ('あ'/'𠮷'/'🎉' 全体2セルにぴったり一致) │
│   行末の空セル (x=12, 1セル幅):          $ echo あ𠮷█    (1セル幅の塗りつぶしブロック)         │
│   IME変換中 (preedit = "にほん"):        $ にほん        (従来通り選択色下敷き + アクセント下線) │
└───────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ ターミナル (フォーカス中・ライト: 背景 #FCFBF8 / カーソル塗 #24282C / 反転字 #FCFBF8) 760px ─┐
│   日本語・4Byte文字上 (x=2, 2セル幅):    $ ██あ██いう𠮷  (白固定ではなく濃色 #24282C 塗 + 紙色字)│
└───────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ ターミナル (非フォーカス・分割ペイン反対側: 1px #CED4DE / #24282C 中抜き枠) ───────── 760px ─┐
│   英文上のカーソル (x=2, 1セル幅):       $  frame[e]llo       (1セル中抜き枠・文字色は元のまま) │
│   日本語・4Byte文字上 (x=2, 2セル幅):    $ frame[あ]いう𠮷    (2セル中抜き枠・文字全体と一致)   │
└───────────────────────────────────────────────────────────────────────────────────────────────┘
```

States covered:
- **Empty / 出力待ち**: `ターミナル出力を待っています…` を表示し、カーソルは描画しない (`lines` が `None`)。
- **スクロールアウト / リサイズ直後の幅超過**: ビューポート外または右端 (`inner_right + 0.5`px) を超えるカーソル（2セル幅で右端からはみ出す場合を含む）は `None` となり枠外へ描画しない。
- **セッション終了・失敗 (`Exited` / `Failed`)**: フォーカス有無にかかわらずカーソルを描画しない。
