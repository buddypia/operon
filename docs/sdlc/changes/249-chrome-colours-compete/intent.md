# Intent: competing chrome colours

- **Status**: approved

## Problem

The user sees orange primary actions beside blue selections in the dark session workspace. They ask: 「オレンジ色だったり青色だったりなっているけど、統一した方がよいんじゃない？シンプルに業界標準にしたい。…ダークモードだと黒と灰色とかを主に使っているっぽい。それに合わせたい。」

## Outcome

A quiet black and grey application frame, with clear selection and primary action hierarchy. Semantic status, diff and terminal colours keep their meanings.
