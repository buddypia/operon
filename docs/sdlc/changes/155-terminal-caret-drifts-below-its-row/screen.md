# Screen: ターミナルペインのカーソル枠の位置

## 問題

履歴のあるセッションで、tmux が報告するカーソル位置(CLI の入力欄の行 / 列)と、
ペインが描くブロックカーソルの位置がずれ、入力欄の下の行に重なって描かれる。
 tl;dr: カーソル枠のアンカーがビューポート上端、行のアンカーが
ScrollArea コンテンツ上端なので、スクロールオフセットが生じると常にずれる。

実際の幅: セッション右ペインのターミナル枠、92 列 x 36 行、等幅 15px。

## Before (バグ)

    +-- ターミナル ---------------------------------------------------+
    | ... ここに履歴が入り、下端に寄せて表示される ...                 |
    | > /model                                                       |
    |   Dump  Model set to Gemini 4 Argon (High)                     |
    |   | Meet Gemini 4 Argon                                        |
    |   | Google's most capable frontier model ...                   |
    |   | esc to dismiss                                             |
    | ---------(罫線)------------------------------------------------ |
    | >                                                              |
    | ^-- ここにカーソル枠が描かれるべき                              |
    | [cursor] <- しかし枠は下の罫線の行にずれて描画される             |
    | ---------(罫線)------------------------------------------------ |
    | ? for shortcuts                  Gemini 4 Argon - hig          |
    +----------------------------------------------------------------+

## After (修正後)

    +-- ターミナル ---------------------------------------------------+
    | ... ここに履歴が入り、下端に寄せて表示される ...                 |
    | > /model                                                       |
    |   Dump  Model set to Gemini 4 Argon (High)                     |
    |   | Meet Gemini 4 Argon                                        |
    |   | Google's most capable frontier model ...                   |
    |   | esc to dismiss                                             |
    | ---------(罫線)------------------------------------------------ |
    | > [cursor] tmux と同じセル(行/列)に置かれる                     |
    | ---------(罫線)------------------------------------------------ |
    | ? for shortcuts                  Gemini 4 Argon - hig          |
    +----------------------------------------------------------------+

## 状態

- フォーカス中: 枠を入力欄と同じセルに描く (Before のずれを解消)
- IME 変換中: 変換文字列の下敷きと候補ウィンドウの rect も同じセル
- ユーザーが上へスクロールしてカーソル行が見えない: 枠を描かない
  (見えない行に浮かんだ枠は残さない)
- 操作なし・出力待ち ( IMEなし ): 枠なし ( 変わらず )

## ルール

枠は「キャレット行が並ぶ座標系」にアンカーする。行を描くのにつかった
同一の基準 ( コンテンツ上端 + 行番号 x 行高 ) を使い、行の描画と一致させる。
