# Operon

- Work that adds user-visible behaviour, touches multiple modules, changes a persisted shape, adds a dependency, or alters a policy runs through `docs/sdlc/README.md` (`intent.md`, `spec.md`, `plan.md`); a typo or one-line fix does not. `docs/sdlc/routes.yaml` sets mandatory stages and attempt ceilings; `docs/sdlc/risk.yaml` sets autonomy; `bash scripts/check-readiness.sh <change-dir>` gates stage 3.
- If a directory exists under `docs/sdlc/changes/`, read its `state.yaml` first: route, stage, what is spent, and `resume`.
- Stopping is a state: record `awaiting-user`, `blocked`, or `failed`; at the attempt ceiling write `handoff.md` from `docs/sdlc/templates/handoff.md`.
- Ask a person only for a decision that would be unrecoverable if wrong. Anything a revert, re-run, or review undoes, decide, record in `state.yaml`, and do. Never hand a person a command to type: a recoverable step a guard refuses is a gap in the guard, and the fix goes there (sdlc 084).
- Write to a person in their words: what happens, when, and whether they must act — never this repository's review vocabulary (nit, carry, digest, round). Unfixed findings reach them through the `person:` line in `review.yaml` (sdlc 085).
- `git commit` runs `cargo fmt --check` and `cargo clippy --locked -- -D warnings` via `.claude/hooks/gate-commit.sh` and refuses lost tests or new `#[ignore]`; `cargo test --locked` runs in CI on push, so locally run only named tests. `REVIEW.md` is the review policy; `docs/sdlc/lessons.md` records recurring mistakes.
- `.cli/hooks/commit-guard.mjs` refuses commits on `main`. Work in a worktree (`make wt.new BR=feature/<task>`) and commit from that directory (`.claude/hooks/gate-commit.sh` refuses `git -C` aimed elsewhere). Push the branch, merge on `main` with `git merge --no-ff --no-edit` once CI passes (`.claude/hooks/gate-merge.sh`), `git push origin main`, and clean up from `main` via `node .claude/scripts/create-pr/ops.mjs cleanup-worktree --worktree <path>`. `.cli/hooks/destructive-git-guard.mjs` blocks `reset --hard`, `push --force`, `clean -f`, and `stash clear`.
- `.claude/skills/create-pr/SKILL.md` does not run here. `.claude/skills/ship/SKILL.md` is the post-landing release.
- After changes, run `bash scripts/package-macos.sh` (runs fmt/clippy, `--full` adds tests, writes `dist/Operon.app` without hand-editing), then atomically replace `/Applications/Operon.app` via `scripts/replace-macos-bundle.sh` per `.claude/skills/ship/SKILL.md`, trashing obsolete bundles unless a rollback copy is requested. Quit the running app before manual verification.
- Six `#[ignore]`d tests need a live agent CLI; run `cargo test --locked -- --ignored` when touching restore or the shared-session archive, or state that you could not.
- Develop or modify features through `.claude/skills/feature-pilot/SKILL.md`.
